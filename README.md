# 🎮 Mona Mayhem
## Build Your GitHub Contribution Battle Arena with AI

Ready to level up your GitHub workflow? Welcome to **Mona Mayhem** — an immersive workshop where you'll build a retro arcade game that gamifies GitHub contributions.

![Mona Mayhem Screenshot](https://github.com/user-attachments/assets/5eca79e2-cb9f-4e93-aa0d-23666ebde3b7)
*Your finished arcade battle arena awaits*

### 🎯 What You'll Build

Battle your collaborators in a **retro-arcade showdown** — compare GitHub contribution graphs head-to-head while mastering modern AI-assisted development. By the end of this workshop, you'll have built a full-stack web app powered by GitHub Copilot.

### 🧠 What You'll Master

- 🤖 **AI-Powered Development** — Let GitHub Copilot handle the heavy lifting while you focus on architecture
- 🎮 **Full-Stack Web Apps** — From API design to frontend polish, all with Copilot assistance
- 🏗️ **Effective Prompting** — Learn how to communicate with AI for maximum development velocity
- ⚡ **Agentic Workflows** — Use autonomous agents and CLI tools for hands-off coding
- 🎨 **AI + Design** — Combine creative vision with AI-assisted implementation
- 💪 **Real Projects** — Build something playable and shareable from day one

## 🚀 Get Started in 3 Minutes

Ready to build? Let's go:

1. **Create your playground**
   - Click **Use this template** to fork the repo, or
   - Fork this repository directly
2. **Choose your weapon**
   - **VS Code**: Clone locally, open in VS Code, fire up Copilot
   - **CLI**: Clone locally, install `copilot`, work from terminal
3. **Follow the guide** — Head to [workshop/00-overview.md](workshop/00-overview.md) and start building

That's it. The rest happens in code.

## ✅ Prerequisites

**The essentials:**
- ✨ GitHub Copilot (Pro, Business, or Enterprise)
- 🔗 Git
- 📦 Node.js

**For VS Code track:**
- 📝 VS Code v1.107+
- 🤖 GitHub Copilot extension (signed in)

**For CLI track:**
- 🖥️ GitHub Copilot CLI (`copilot`)
- 📦 Node.js 22+ (for npm install)
- 🍺 Or use Homebrew / WinGet for system-level installation
